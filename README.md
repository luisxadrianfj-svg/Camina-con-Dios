# Camina con Dios

Aplicación de acompañamiento espiritual diario, desarrollada inicialmente como PWA con Next.js.

El proyecto incluirá versículos bíblicos, reflexiones con inteligencia artificial, contexto histórico de las Escrituras, diario de oración y gratitud, favoritos y preferencias personales.

Tecnologías previstas: Next.js, Supabase e integración de IA.

Estado: desarrollo inicial del MVP 0.1.
